# Docker Forgery
This repo contains all the necessary files to generate all the containerized
environments needed for all the variton projecst.

## cxx-core
C++ core forgery to build C++ packages and software.

### debian
Debian based C++ env with GCC 14.

### ubuntu 
Ubuntu based C++ env with GCC 15.

## py-core
Python core forgery to build python packages.

## xpylib 
Python High level Python packages forgery.

## ci
CI forgery for CI pipelines on Github & Gitlab

## streaming 
Streaming forgery for video streaming.
